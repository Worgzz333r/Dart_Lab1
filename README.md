# lab_dart — Барна карта коктейлів

Консольний застосунок на Dart (варіант 5) для ведення барної карти коктейлів. Дані можна імпортувати з відкритого REST API [TheCocktailDB](https://www.thecocktaildb.com/api.php), зберігати у файл `data.json` і відновлювати під час наступного запуску.

Лабораторна робота №1 «Створення консольного застосунку на Dart» з дисципліни «Кросплатформенне програмування» (Волинський фаховий коледж Національного університету харчових технологій, група ІПЗ-42). Flutter не використовується.

## Запуск

Потрібен Dart SDK `^3.12.0`.

```bash
dart pub get
dart run bin/main.dart
```

Запускайте з кореня проєкту: файл `data.json` читається й записується відносно поточної папки.

## Меню

Застосунок інтерактивний: потрібний пункт обирається введенням номера.

```
=== Барна карта коктейлів ===
1. Показати список
2. Додати коктейль
3. Видалити коктейль
4. Завантажити з API
5. Пошук
6. Сортування
0. Вихід
```

| Пункт | Що робить |
|-------|-----------|
| 1 | показує нумерований список коктейлів |
| 2 | додає коктейль: назва (обов’язкова), категорія (за замовчуванням «Невідомо»), тип, інгредієнти через кому |
| 3 | видаляє коктейль за номером зі списку |
| 4 | шукає коктейлі в TheCocktailDB за назвою й додає лише ті, яких ще немає (за `id`) |
| 5 | пошук за частиною назви без урахування регістру |
| 6 | сортування за назвою або за категорією (без урахування регістру) |
| 0 | вихід |

Тип напою під час додавання: `1` — алкогольний, `2` — безалкогольний, будь-що інше — «за бажанням».

Усі зміни (додавання, видалення, імпорт, сортування) одразу записуються в `data.json`, тож порядок після сортування зберігається й між запусками.

## Обробка помилок

Некоректний ввід не завершує програму: невідомий пункт меню, порожня назва чи запит, неправильний номер для видалення — усе це дає повідомлення й повернення до меню. Помилки імпорту з API також оброблено окремо:

| Ситуація | Реакція |
|----------|---------|
| немає інтернету (`SocketException`) | повідомлення, робота з локальними даними триває |
| відповідь сервера не 200 (`ApiException`) | повідомлення «Сервер недоступний» |
| некоректний JSON (`FormatException`) | повідомлення «Сервер повернув некоректні дані» |
| будь-яка інша помилка | повідомлення з текстом помилки |

Якщо `data.json` відсутній, застосунок стартує з порожнім списком. Якщо файл пошкоджений, має неправильну структуру або некоректні значення, програма повідомляє про це й також починає з порожнього списку.

## Використане API

Відкрите API TheCocktailDB, реєстрація не потрібна — у шляху запиту вказується тестовий ключ `1`.

```
GET https://www.thecocktaildb.com/api/json/v1/1/search.php?s=mojito
```

| Параметр | Призначення |
|----------|-------------|
| `s` | пошуковий запит (частина назви коктейлю) |

Із відповіді використовуються поля `idDrink`, `strDrink`, `strCategory`, `strAlcoholic` та `strIngredient1` … `strIngredient15` масиву `drinks`. Якщо нічого не знайдено, API повертає `drinks: null`, а не порожній масив — сервіс враховує це й повертає порожній список.

Скорочений приклад відповіді:

```json
{
  "drinks": [
    {
      "idDrink": "11000",
      "strDrink": "Mojito",
      "strCategory": "Cocktail",
      "strAlcoholic": "Alcoholic",
      "strIngredient1": "Light rum",
      "strIngredient2": "Lime",
      "strIngredient3": "Sugar",
      "strIngredient4": "Mint",
      "strIngredient5": "Soda water",
      "strIngredient6": null
    }
  ]
}
```

```
│   ├── services/

│   │   └── cocktail_api_service.dart   запити до TheCocktailDB

│       └── cocktail_utils.dart         пошук і сортування (searchLocal, sortCocktails)

│   └── cocktail_test.dart              модульні тести

├── CHANGELOG.md
├── data.json                           збережені дані
└── pubspec.yaml                        залежності проєкту
```

Логіка розділена за призначенням: мережа ізольована в `cocktail_api_service.dart`, робота з файлом — у `cocktail_repository.dart`, а пошук і сортування — у `cocktail_utils.dart`. Меню в `bin/main.dart` лише поєднує ці частини. `sortCocktails` не змінює вхідний список, а повертає відсортовану копію.

## Модель даних

`Cocktail` реалізує абстрактний клас `Storable` і пов’язаний з моделлю `Category` та переліченням `AlcoholType`.

| Поле | Тип | Опис |
|------|-----|------|
| `id` | `String` | ідентифікатор (`idDrink`) |
| `name` | `String` | назва коктейлю |
| `category` | `Category` | категорія |
| `type` | `AlcoholType` | алкогольний чи безалкогольний |
| `ingredients` | `List<String>` | інгредієнти |

Методи: `toJson()`, `fromJson()` (читання з `data.json`), `fromApi()` (розбір відповіді TheCocktailDB) і `toString()`.

## Що використано з мови

- `dart:io`, `dart:convert` — `File`, `stdin` / `stdout`, `jsonEncode` / `jsonDecode`, `JsonEncoder.withIndent`
- `async` / `await`, `Future` — запити до API та робота з файлом
- пакет `http` — `http.Client` передається в сервіс через конструктор
- абстрактні класи й інтерфейси — `Storable`, `implements`
- перелічення — `AlcoholType` (`alcoholic`, `nonAlcoholic`, `optional`), `SortField` (`name`, `category`); `byName`, `name`, `label`
- `factory`-конструктори — `fromJson`, `fromApi`
- null safety — `String?`, `??`, `?.`
- `switch`-вирази й оператори в меню, виборі типу та полі сортування
- колекції — `map`, `where`, `any`, `sort`, `toList`, каскадна нотація `..clear()..addAll()`
- `try` / `on` / `catch` і власний виняток `ApiException`
